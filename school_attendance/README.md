# School Attendance System

Simple school attendance system — mark students **Present (P)** or **Absent (A)** by roll number.

## Setup

```bash
pip install -r requirements.txt
python app.py
```

Open → http://localhost:5000

## Features
- Roll-number based attendance (no names needed)
- 5 classes (Class 1–5), 40 students each
- Mark individual or bulk (All Present / All Absent)
- Date picker — mark any past date
- Class summary cards with percentage
- Reports page — per-roll attendance % with Regular / Average / Irregular status
- Export CSV per class per date
